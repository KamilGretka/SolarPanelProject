# ☀️ SolarPanelProject

A student project for managing and simulating a system related to photovoltaic panel installations.

The project was developed in C# using the .NET platform and Windows Forms.  
The main goal was to create an application with separate modules responsible for data, application logic, configuration, and communication with external devices.

## 📌 About the Project

SolarPanelProject was created as part of an academic project.

The application was designed in a modular way, with individual components responsible for configuration, data, models, and application logic organized into separate directories.

The project also includes modules responsible for port communication and script handling.

## 🛠️ Technologies

- **C#**
- **.NET Framework**
- **Windows Forms**
- **Visual Studio**
- **Git / GitHub**

## 🧩 Project Structure

```text
SolarPanelProject/
│
├── Configuration/       # Application configuration
├── Data/                # Data used by the application
├── Enums/               # Enumeration types
├── Logic/               # Application logic
├── Models/              # Data models
├── Output Messages/     # Output messages
├── Port/                # Port communication

│
├── MainWindow.cs        # Main application window
├── MainWindow.Designer.cs
├── MainWindow.resx

│

```
